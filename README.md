## Title
Shopping Cart

## Description
A three pages (home page, shop page, and cart page) project that implements shopping cart which allows user to add items to cart, remove items in cart, and modify its quantity.

## Technologies
HTML: structure
React JS: structure and functionality
React Router: client-side routing
Jest & RTL (React Test Library): UI testing
CSS module: layout and styling
Netlify: project deploy
